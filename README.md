# Калькулятор семейной налоговой выплаты за 2025 год

Открыть: https://semvyplata.github.io

Одностраничный калькулятор права на ежегодную семейную выплату (ФЗ от 13.07.2024 № 179-ФЗ,
постановление Правительства РФ от 27.12.2025 № 2173).

Проверяет заявителя по всем критериям, которые применяет СФР: количество детей, состав семьи,
среднедушевой доход против порога 1,5 регионального прожиточного минимума, имущественный ценз
(недвижимость, земля, транспорт), задолженность по алиментам, наличие облагаемого НДФЛ дохода.
Считает размер выплаты для каждого родителя отдельно.

Всё считается в браузере. Персональные данные не собираются и никуда не передаются.

**Информационный расчёт, не является налоговой или юридической консультацией.**
Решение о назначении выплаты принимает Социальный фонд России.

## Файлы

- `index.html` — калькулятор, блок продукта, подвал с реквизитами. Зависимостей нет
- `oferta.html` — публичная оферта на цифровой товар + реквизиты продавца
- `privacy.html` — политика конфиденциальности

## Перед подключением кассы

Платёжные системы (ЮKassa, Продамус) проверяют сайт вручную. Модератор должен увидеть
товар, цену, порядок выдачи, оферту и реквизиты **без регистрации и без заполнения формы**.
Всё это на сайте есть, кроме личных данных — их нужно подставить.

### 1. Реквизиты — подставлены

ФИО, ИНН, адрес, почта и телефон уже проставлены в подвале `index.html`,
в разделе 10 оферты и в разделе 9 политики. При смене любого значения
править во всех трёх файлах.

### 2. Вставить ссылку оплаты

В `index.html`, в начале блока `<script>`:

```js
const PAY_URL = "";   // ← ссылка платёжной страницы ЮKassa
```

Пока строка пустая, кнопка «Купить» никуда не ведёт. После подключения кассы вписать ссылку —
она подставится в кнопку автоматически.

### 3. Что указать в анкете

- **Адрес сайта:** `https://semvyplata.github.io`
- **Ссылка на страницу с реквизитами:** `https://semvyplata.github.io/oferta.html`
- **Данные для входа:** не нужны, закрытых разделов нет

## Правки

- Кнопка в результате расчёта — константа `SALES_URL`, ведёт на якорь `#product`
- Ссылка оплаты — константа `PAY_URL`
- Прожиточные минимумы по регионам — массив `REGIONS`
- Цена указана в трёх местах `index.html`: блок `.price`, текст кнопки `#buy`,
  подпись под кнопкой в результате расчёта. При смене 490 → 990 поправить все три,
  плюс п. 3.1 оферты
