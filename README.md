# Калькулятор семейной налоговой выплаты за 2025 год

Открыть: https://semvyplata.github.io

Одностраничный калькулятор права на ежегодную семейную выплату (ФЗ от 13.07.2024 № 179-ФЗ,
постановление Правительства РФ от 27.12.2025 № 2173).

Проверяет заявителя по всем критериям, которые применяет СФР: количество детей, состав семьи,
среднедушевой доход против порога 1,5 регионального прожиточного минимума, имущественный ценз
(недвижимость, земля, транспорт), задолженность по алиментам, наличие облагаемого НДФЛ дохода.
Считает размер выплаты для каждого родителя отдельно.

Всё считается в браузере. Персональные данные не собираются и никуда не передаются.

**Информационный расчёт, не является налоговой или юридической консультацией.**
Решение о назначении выплаты принимает Социальный фонд России.
